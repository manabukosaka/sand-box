# Visual & UX Verification (VUV) チェックリスト

UI修正を伴うプルリクエストを作成する際は、必ず本チェックリストを消化し、PRのディスクリプションまたはコメントにエビデンス（スクリーンショット、計測結果など）を添付してください。

## 1. アクセシビリティ (Accessibility)
- [ ] 主要なテキスト要素（見出し、本文、ボタンのラベルなど）のコントラスト比が **WCAG AA (4.5:1, 大きなテキストは 3:1)** 以上であることを確認した。
  - *エビデンス: Lighthouseやコントラストチェッカーツールの結果スクリーンショット等*

## 2. 視覚的整合性 (Visual Consistency)
- [ ] グリッドシステム（例: TailwindのグリッドやFlexbox）に基づいた配置が行われている。
- [ ] コンポーネント間やセクション間の余白（Spacing）がプロジェクトのデザインシステム・ルールと一貫している。
  - *エビデンス: 適用した余白のクラス名（`gap-4`, `p-6` など）や、レイアウトが崩れていないことを示すスクリーンショット*

## 3. 直感性 (Intuitiveness)
- [ ] アイコンやボタン単体でも、ツールチップやラベルなしに機能が直感的に推測・理解できる（または適切な補助テキスト・ARIAラベルが提供されている）。
- [ ] ユーザーの主要な導線が明確であり、迷うことなく目的の操作に辿り着けるか再検証した。
  - *エビデンス: 操作フローのGIF動画、または「機能がどう直感的に理解できるか」の簡単な説明*

---
*※ 全ての項目にチェックを入れ、エビデンスと共に提出することでVUVプロセスが完了となります。*
