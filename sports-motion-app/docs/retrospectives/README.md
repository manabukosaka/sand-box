# Sports Motion App Retrospectives

Retrospectives convert repeated process friction into durable repository
guidance, scripts, tests, or planning updates.

Create a dated note when:

- autonomous work needed repeated manual steering;
- review request gates were missed or unclear;
- PR, merge, verification, or post-merge workflow failed;
- sub-agent sidecar review found a reusable harness gap;
- process or product improvement was deferred and needs tracking.

Each retrospective should include trigger, what happened, root causes, permanent
corrections, and validation. Do not include exact test counts or pass totals.
